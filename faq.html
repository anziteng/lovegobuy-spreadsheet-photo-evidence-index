Lovegobuy Spreadsheet Evidence FAQ

Questions and evidence boundaries for this Lovegobuy Spreadsheet photo evidence index task.

Scope

What should one photo-evidence indexing review cover?

Cover one decision and produce a photo evidence index tying each saved image to a row, observation date, visible feature, and follow-up question. If several rows or unrelated questions are involved, split them into separate records so each conclusion has its own evidence and next action.

The minimum input is one row, its saved images, image order, visible features, and capture dates. Missing inputs should be listed as gaps rather than filled from a similar row or an old memory.

  • Name the single row, source, or field set in scope.
  • State the decision that the review must produce.
  • List unavailable inputs before opening more sources.

Evidence

What counts as usable evidence?

Usable evidence is visible, attributable to a source, and dated. Copy exact wording for selections and fields, preserve the path needed to reopen the source, and explain any interpretation in a separate sentence.

A screenshot or saved value can document an earlier observation, but it does not prove that a changing field is still current. Recheck live details before making a new decision.

  • Keep exact option, size, label, or field wording.
  • Attach the source path and observation time.
  • Mark reviewer interpretation separately from visible facts.

Exceptions

What happens when sources disagree?

If an image cannot be tied to the same row and option, keep it unassigned instead of using visual similarity as identity proof. Keep both observations, label the conflict, and identify the smallest check that could resolve it.

Do not choose the more convenient value merely because it makes the row look complete. An unresolved state is safer and more useful than a fabricated certainty.

  • Preserve each conflicting observation and its date.
  • Explain how the disagreement affects the decision.
  • Assign one source or field for the next check.

Output

How can another reviewer verify the result?

The final note should include the scoped question, accepted evidence, rejected alternatives, the decision, and a dated next action. Another reviewer should be able to reopen the same source and understand why the result was reached.

If the result changes later, append a replacement observation and explain the trigger. Preserving the sequence provides a clearer audit trail than overwriting the original record.

  • Summarize accepted evidence and rejected alternatives.
  • Name the decision owner and the next review date.
  • Append later changes instead of erasing the earlier result.
